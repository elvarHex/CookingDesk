## 🍳 About the App

Cooking Desk is your new recipe book.  
You can discover new recipes, cook them step by step, and save them.  
You can also create your own recipes.

---

## ✨ Features

- 👨‍🍳 Step-by-step cooking mode
- 🛠️ Useful tools
- 🙌 Hands-free
- 📖 Discover new recipes  
- 💾 Save your favorite recipes  
- ✍️ Create and customize your own recipes
